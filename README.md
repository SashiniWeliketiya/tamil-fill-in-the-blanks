# 🌟 Tamil Fill in the Blanks Activity (பூர்த்தி செய்வோம்)

An interactive, kid-friendly educational web application designed to practice Tamil vocabulary and spelling through a fun "Fill in the Blanks" activity! 

---

## 🚀 Live Demo
You can view the live website here: 
👉 ( https://sashiniweliketiya.github.io/tamil-fill-in-the-blanks/)

---

## ✨ Features
* **Interactive Learning:** Designed for students to practice Tamil words (வாசித்தல் - எழுதுதல்).
* **Instant Validation:** Checks user answers immediately upon clicking the check button.
* **Smart Scoring:** Displays total scores and gives encouraging visual feedback (color-coded highlights for correct and incorrect answers).
* **Responsive Design:** Works smoothly on both mobile phones and desktop computers.

---

## 🛠️ Built With
This project is built using pure frontend web technologies:
* **HTML5** - For page structure and content.
* **CSS3** - For modern, playful styling, gradients, and layouts.
* **JavaScript (ES6)** - For interactive logic, input validation, and score calculation.
